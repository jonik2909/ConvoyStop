# ConvoyStop project memory

Work only in this checkout unless the user requests otherwise. User updates are in Uzbek. UI defaults to concise Korean, with an English dictionary fallback.

Read docs/PRODUCT.md, docs/ARCHITECTURE.md, docs/DESIGN.md and docs/PROGRESS.md before changing behavior. Update PROGRESS after a verified milestone. Never call an untested flow complete.

## Non-negotiable product boundaries

- iOS-first React Native companion. Not an official Kia/Hyundai product.
- Pleos Connect Vehicle SDK targets Android Automotive OS. Do not pretend it runs on iOS or ordinary Android phones.
- Real group server, durable storage, validated state transitions, version-scoped decisions, per-member navigation and arrival.
- Manual/demo telemetry must be visibly labeled. A percentage is not remaining range. Never promise reachability.
- Seed stops/services/detour minutes are illustrative, not live availability or routing. A live StopProvider can replace them later.
- No account wall. A device token authenticates each temporary trip member. Invite codes are shared only by explicit system share actions.
- No fake successes or no-op controls. Offline actions fail visibly and require an explicit retry; do not replay stale decisions.
- Use current simulator evidence; preserve unrelated user files. Never spawn agents merely because this file exists.

## Layout

- apps/mobile: Expo Router iOS UI, query cache, local session, platform adapters.
- apps/server: HTTP + WebSocket API and SQLite store.
- packages/domain: schemas, contracts, ranking, state machine.
- docs: decisions and honest current status. evidence: screenshots, recordings and verification output.

Commands are documented in README.md once scaffold is complete. Dependencies are pinned by package-lock.json. Secrets and runtime database files never enter Git. Native ios is generated by Expo prebuild and must be build-verified. Simulator actions and local package installation are authorized by the user.

## Working method

Apply appllama-app-design-skill and unslop. Study references before UI work. Run typecheck, lint and meaningful domain/API integration tests. Launch iOS Simulator, inspect screenshots in both themes, exercise keyboard/back/sheets, record full flows and inspect motion. Respect Dynamic Type, Reduce Motion, safe areas and 44pt controls. Do not claim measured 60fps without release-device profiling.
